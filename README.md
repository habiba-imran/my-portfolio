# Habiba Imran Portfolio

Personal portfolio built with Next.js, Tailwind CSS, GSAP, and React.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Build

```bash
npm run build
```

## Content

Main portfolio copy and project data live in:

- `components/`
- `lib/data.ts`
- `app/layout.tsx`
